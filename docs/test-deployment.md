# 测试环境部署说明

当前 AppID：`wxc071e07c585e25bd`

当前没有云开发能力，因此测试环境采用：

- 本地 `wx.storage` / 浏览器 `localStorage` 存档
- Mock 云端适配器
- Mock 排行榜数据模型
- 不调用真实云函数
- 不保存实时位置、血量等运行时数据

## 当前玩法

- 浏览器入口和微信小游戏入口均先显示加载/兜底画面，再进入主页面；资源优先使用项目内 `assets/`，失败时使用绘制兜底。
- 两个入口均先选择“新的开始”或“重新开始”；新的开始从初始等级开始，重新开始继承上次结束时体型。
- 游戏结束后点击任意位置回到主页面；排行榜在各自端本地保留分数最高的 5 条记录。
- 主菜单按钮路由：新的开始进入初始体型游戏，重新开始继承上次结束体型，自定义进入资源设置页，排行榜进入排行榜页；浏览器版另有手动存档和读取存档按钮。

- 技能每 30 秒出现一次。
- 每条鱼上方显示体型数字，玩家只能优先吞噬体型小于自己的鱼。
- 玩家鱼上方的数字是当前体型。
- 吞噬成功后体型至少增加 2，鱼会立即从屏幕消失并重新生成。
- 技能持续时间：全屏吞噬 4 秒、同类吞噬 3 秒、极速冲刺 3 秒、巨型成长 2 秒、生命恢复 2 秒、无敌护盾 4 秒。
- 技能持续期间会持续处理范围内的鱼，并且每次吞噬后立即补充新鱼。
- 随玩家实际体型增大，屏幕显示会自动缩放；鱼身数字显示实际体型，不随缩放改变。
- 鱼分为五种外观：普通鱼、圆斑鱼、光环鱼、尖鳍鱼和绿尾鱼；玩家鱼会随实际体型阶段自然变大。
- 黄色技能球下方显示技能名称，靠近后自动拾取。
- 全屏吞噬：黄色扩散圈、张嘴“吸”字和粒子效果。
- 同类吞噬：蓝色范围圈。
- 极速冲刺：黄色速度线。
- 巨型成长：粉色扩散光环。
- 生命恢复：绿色光圈和“+”标记。
- 无敌护盾：紫色护盾圈。

操作方式：手指按住并拖动，玩家鱼会跟随手指移动；吃掉数字比自己小的鱼，避开数字比自己大的鱼。

## 微信开发者工具导入

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择：`D:\worksoft\video\fish-game`。
4. AppID 使用：`wxc071e07c585e25bd`。
5. 项目类型选择“小游戏”。
6. 导入后点击“编译”。

项目根目录已包含微信小游戏必需的 `game.json` 和 `game.js`。当前不使用 Worker，也不主动读取设备信息，因此 `game.json` 不配置 `workers` 和方向字段。浏览器版使用 `index.html`，微信小游戏版使用 `game.js`，两者是独立入口。
