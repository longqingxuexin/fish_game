# 自定义资源跨端对齐

## 端与入口

| 端 | 入口 | 缓存 |
| --- | --- | --- |
| 浏览器 | `src/main.ts` 的“自定义”按钮 | `localStorage` |
| 微信小游戏 | `game.js` 菜单中的“自定义”按钮 | `wx.setStorageSync`，图片使用小游戏本地临时文件 |

## 统一资源类型

`player`、`small`、`big`、`boss`、`background`，以及 `global_eat`、`type_eat`、`speed_up`、`grow`、`heal`、`invincible` 六种技能特效。

鱼类资源支持 `speed`；技能资源支持 `durationMin` 和 `durationMax`。特效图片按上传顺序作为动画帧。

## 图片处理规则

鱼类和技能图片使用边缘四连通区域识别浅灰/浅白背景，默认背景图不经过抠除处理。算法只从画布边缘开始扩散，因此鱼体内部的白色高光不会被误删；输出时清理透明像素 RGB 和亮色半透明边缘。

## 开始游戏注入规则

- 自定义主角替换默认主角。
- 自定义鱼加入对应类型的生成池，而不是只额外生成一次。
- 自定义背景替换默认背景。
- 自定义鱼速度覆盖对应鱼的默认速度。
- 技能持续时间在配置的最短/最长秒数之间随机取值。
- 关闭自定义页面或开始游戏前保存当前编辑值。
