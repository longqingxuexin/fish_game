# 上线操作清单（小白版）

## 你只需要做的事情

1. 注册并登录微信公众平台，申请“小游戏”，取得 AppID。
2. 安装微信开发者工具并登录同一个微信账号。
3. 打开本目录 `D:\worksoft\video\fish-game`。
4. 在 `project.config.json` 中把 `appid` 替换为你的真实 AppID。
5. 在开发者工具中创建云开发环境，记录环境 ID。
6. 把云环境 ID 告诉我，我会把客户端云初始化配置补上。
7. 你在开发者工具中点击“预览”，用手机验证核心玩法。
8. 你确认没有问题后，在开发者工具中点击“上传”。
9. 在微信公众平台提交审核。审核中的实名、健康系统和小游戏类目资料必须由账号主体完成。

## 我可以继续完成的事情

- 接入你提供的 AppID 和云环境 ID。
- 完成云函数部署目录和数据库初始化脚本。
- 接入开放数据域排行榜。
- 增加隐私政策、用户协议、未成年人保护入口。
- 根据真机反馈修复问题。
- 生成最终构建版本并做上线前检查。

## 我不能代替你完成的事情

- 登录你的微信账号。
- 申请或实名认证小游戏主体。
- 获取你的 AppID、AppSecret 或云环境权限。
- 代替你提交微信审核。
- 代替你接受实名、健康系统和隐私政策相关的法律责任。

## 不要发给我

- AppSecret
- 登录密码
- 短信验证码
- 身份证照片
- 人脸或实名认证原始资料

只需要提供 AppID 和云环境 ID，不要提供密钥。
