# 微信云开发配置清单

## 免费前提

只使用微信云开发当前免费额度。正式上线前在微信开发者工具的云开发控制台确认额度、数据库容量、云函数调用次数和开放数据域能力；本地原型不依赖云端也可以运行。

## 数据库集合

- `player_profiles`：每个用户一条持久化存档。
- `game_records`：战绩摘要，不保存位置、实时血量或实名原始资料。
- `game_config`：配置文档，创建 `_id=default` 的文档。

## 云函数部署

在微信开发者工具中将 `cloudfunctions` 目录设置为云函数根目录，分别上传部署：

- `loadSave`
- `saveGame`
- `submitRecord`
- `getGameConfig`

每个函数均使用 `wx-server-sdk`，由平台注入 `userInfo.openId`。客户端不得自行传入或覆盖用户身份。

## 安全规则

- 客户端不能直接写 `player_profiles` 和 `game_records`。
- 存档写入必须经过 `saveGame` 校验。
- 不保存身份证、姓名、手机号、人脸、精确位置或实名原始响应。
- 云函数日志不得打印完整事件对象。

## 验证顺序

1. 先用开发者工具本地调用云函数。
2. 测试首次读取、首次保存、重复保存和断网回退。
3. 提交负数分数、超大金币和缺少身份的请求，确认被拒绝。
4. 确认数据库中只有持久化字段。
5. 再配置开放数据域和排行榜提交。
